Screen Reader Access

LabelSetu is committed to ensuring that the portal is accessible to all citizens and stakeholders, regardless of the technology, device, or assistive software they use. This page provides detailed information regarding screen reader compatibility, recommended assistive technologies, keyboard navigation shortcuts, and browser zoom controls.

Screen Reader Compatibility

The LabelSetu portal complies with World Wide Web Consortium (W3C) Web Content Accessibility Guidelines (WCAG) 2.1 level AA standards as well as the Guidelines for Indian Government Websites (GIGW).

Our web pages have been structured to provide maximum accessibility for visitors using assistive technology, including screen reader applications, refreshable Braille displays, and voice command utilities.

🏷️
Semantic Markup & ARIA

Pages use standard HTML5 landmarks, ordered heading hierarchies, and descriptive ARIA roles to support logical auditory navigation.

🖼️
Descriptive Text Equivalents

Non-decorative imagery, state seals, and informational emblems provide alternative text descriptions for screen reader articulation.

⏭️
Skip Navigation Links

A "Skip to Main Content" mechanism is present on every page to enable quick bypassing of repetitive header navigation.

🎯
Consistent Contrast & Focus

Visual elements conform to WCAG contrast standards, and high-visibility focus indicators allow keyboard users to easily track focus.

Accessibility Keyboard Shortcuts

Users who do not use a mouse or pointing device can navigate the portal using the following standard keyboard commands:

Keyboard Key / Shortcut Navigation Action / Behavior
Tab Move focus forward to the next interactive hyperlink, button, or form field.
Shift + Tab Move focus backward to the previous interactive hyperlink, button, or form field.
Enter Activate the currently focused link or trigger a button action.
Spacebar Toggle checkbox selections, press focused buttons, or scroll down one page view.
Alt + ← (or Cmd + [ on Mac) Navigate back to the previously visited page in browser history.
Alt + → (or Cmd + ] on Mac) Navigate forward to the next page in browser history.
Ctrl + F (or Cmd + F on Mac) Open browser search bar to find specific text or keywords on the active page.
Ctrl + Home (or Cmd + ↑ on Mac) Move focus directly to the very top (beginning) of the webpage.
Ctrl + End (or Cmd + ↓ on Mac) Move focus directly to the bottom (footer) of the webpage.
Esc Dismiss open dropdown dialogs (e.g. language selection menu) or modal dialogs.
↑ / ↓ Arrow Keys Scroll page up or down; navigate between options inside select menus and radio buttons.
F6 Cycle keyboard focus between the browser address bar, tab strip, and webpage body.

Browser Zoom Instructions

If you need larger text or want to magnify the portal content, you can use the built-in portal controls or your browser's zoom features:

🔤

Portal Text Size Controls

Quickly adjust the font size across the entire page using the controls in the top navy bar:

  • A-: Decreases the base text size by 2 pixels.
  • A: Resets the base text size to default (14px).
  • A+: Increases the base text size by up to 4 pixels.
🔍

Keyboard Zoom Shortcuts

Scale the complete page (both text and layout) using standard browser keystrokes:

  • Zoom In: Press Ctrl + + (Cmd + + on Mac)
  • Zoom Out: Press Ctrl + - (Cmd + - on Mac)
  • Reset Zoom (100%): Press Ctrl + 0 (Cmd + 0 on Mac)
🖱️

Mouse & Trackpad Scaling

Smoothly scale the display view using your mouse or multi-touch trackpad:

  • Hold Ctrl (or Cmd on macOS) while rotating the mouse wheel forward or backward.
  • On modern touchpads, use two-finger pinch-to-zoom (pinch together to shrink, spread outward to magnify).
🌐

Browser Menu Settings

Adjust the magnification permanently through your browser's application menu:

  • Chrome / Edge / Brave: Open Menu (⋮ or …) > find Zoom > click + or -.
  • Mozilla Firefox: Open Application Menu (☰) > find Zoom > click + or -.
  • Apple Safari: In menu bar, select View > Zoom In or Zoom Out.

Accessibility Assistance & Feedback

We strive to make LabelSetu fully accessible to all individuals. If you experience any barrier or difficulty accessing any content, form, or service on this portal using assistive software, please let us know. You can reach out through the National Consumer Helpline or submit a query to the Department of Consumer Affairs. When reporting an issue, please specify the webpage URL, the nature of the difficulty, and the assistive technology software you are using.

About This Portal

LabelSetu is a product label compliance verification service designed to assist manufacturers, packers, and sellers in verifying whether their product labels carry all mandatory declarations as required under applicable rules.
